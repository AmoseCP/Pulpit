# M0 验收清单 — 透明叠加层技术尖刺

> **这是硬性 go/no-go 门。** 9 项全部通过才能进 M1，任一项失败即停止并回报具体现象。
> 必须在**真实直播机**上验（那台接投影、跑 WPS、跑 OBS 的机器），不是开发机。

---

## 一、跑起来

```powershell
# 需要 .NET 8 SDK。仅 Windows x64 可编译（WPF 不支持在 macOS/Linux 上构建）
git clone <私有仓库地址> Pulpit
cd Pulpit
dotnet build Pulpit.sln -c Debug
dotnet run --project src\Pulpit.App\Pulpit.App.csproj
```

启动后：

- **主屏**出现「Pulpit — M0 技术尖刺」控制窗口
- **副屏**底部三分之一出现半透明黑底带（此刻文字透明度为 0，先按「淡入」）

控制窗口第 ③ 区「实时自检」应显示：

```
扩展样式 正常  LAYERED=✓ TRANSPARENT=✓ TOOLWINDOW=✓ NOACTIVATE=✓ APPWINDOW=无 (0x080800A0)
```

**若这一行显示「扩展样式 异常」，先别往下走** —— 四个位缺任何一个，后面 4/5/6 项一定过不了，
直接回报这一行原文。

> M0 **没有全局热键**。投放一律点控制窗口的按钮。热键是 M4，提前注册只会给
> 「是否误抢 PPT 翻页键」引入无关变量。

## 三、需要重点回报的两项

### 第 7 项：帧率（这一项决定要不要降级为无动画直切）

`AllowsTransparency=true` 会关掉该窗口的硬件加速，淡入淡出是**软件渲染**。
L3 已经把面积限制到带状区域（约 1920×324）来压成本，但成不成得实测。

控制窗口会直接给出实测帧数：

```
上次淡入淡出 15 帧 / 252ms → 59.5 fps
```

判读：

| 实测 | 结论 |
|---|---|
| ≥ 50 fps | 通过，按原设计走 |
| 30–50 fps | 观感可能可接受，需人工判断；把实测值和主观观感一起回报 |
| < 30 fps | **视为第 7 项失败**。停止，回报实测值 —— 需要人工决策是否降级为无动画直切（这会改动 L 层决策，代理不得自行变通） |

### 第 9 项：内存

自检区的「增量」是相对启动时工作集的差值。60 分钟内**持续单调上涨**才是问题；
GC 造成的几 MB 上下波动是正常的。

## 四、失败了怎么办

**不要自行改设计。** §1 锁定决策不得擅自更改。按这个格式回报：

```
失败项：第 N 项
现象：（具体看到什么，不要写「不行」）
自检区原文：（把 ③ 区四行全部贴出来）
环境：Windows 版本 / 副屏分辨率与缩放 / WPS 版本 / 是否 OBS 同时在跑
```

日志在 `%LOCALAPPDATA%\Pulpit\logs\pulpit-<日期>.log`，一并附上。
