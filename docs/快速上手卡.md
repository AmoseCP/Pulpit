# Pulpit 快速上手卡

> 打印成一页 A4，放在直播机键盘旁边。

---

## 五个键，就这些

| 键 | 作用 |
|:---:|---|
| **F9** | 把输入框里的内容**送到副屏**（淡入） |
| **F12** | **清屏**（淡出） |
| **F8** | 下一页 |
| **F7** | 上一页 |
| F10 | 英文经文（v1 未安装，按了会提示） |

**这五个键在任何时候都有效**——哪怕焦点在 WPS 上、你正在放映 PPT。

**方向键、PgUp、PgDn、空格、Esc 仍然归 PPT。** 翻页照旧，不受影响。

---

## 怎么打经文

输入框里打，然后按 **F9**。

| 你想投 | 打什么都行 |
|---|---|
| 约翰福音 3:16 | `约3:16` · `约翰福音3:16` · `yh3:16` · `john3:16` |
| 罗马书 8:28 | `罗8:28` · `罗 8 : 28`（空格没关系） |
| 诗篇 23:1-6 | `诗23:1-6` → 分 6 页，用 **F8** 一页页往下 |
| 约翰壹书 3:16 | `约一3:16` · `约壹3:16`（**不是** `约1:16`） |

全角也认：`约３：１６` 一样能出。

> `约1:1` 是**约翰福音 1 章 1 节**。约翰壹书要打 `约一` 或 `约壹`。

---

## 连续投两处经文

`约3:16;罗8:28` —— 用**分号**隔开，按 F9，用 **F8** 一页页往下。

分号用半角 `;` 或全角 `；` 都行。**逗号和顿号不行**，那些会被当成普通文字。

---

## 怎么投一句普通的话

直接打，比如 `欢迎新朋友`、`今晚 7:30 祷告会`，按 **F9**。
不是经文格式的内容会**原样上屏**。

---

## 只记得内容，忘了出处？

把记得的那句话敲进输入框，点 **「反查出处」**。

```
输入：神爱世人甚至
点「反查出处」→  约翰福音 3:16
                 神爱世人，甚至将他的独生子赐给他们…
```

**双击**结果就投出去；点「填入选中」只填进输入框不投（想改成一段范围时用）。

不用管标点——「神爱世人甚至」和「神爱世人，甚至」都能搜到。
至少要打 **2 个字**；打得越长命中越准。

---

## 投过的经文可以再投

控制窗口的**历史**列表记着本次聚会投过的每一处经文。
**双击**其中一条就再投一次。

单击只是选中，不会上屏——放心点。

---

## 投歌词（多行）

展开「④ 歌词模式」，把歌词粘进去，点 **「投放歌词」**，然后用 **F8** 一段段往下。

**空行就是分页点**——想让哪几行同时上屏，就把它们写在一起，段与段之间空一行：

```
奇异恩典 何等甘甜
我罪已得赦免
                    ← 这一行空着
前我失丧 今被寻回
瞎眼今得看见
```
上面这段会分成 2 页。框下面会实时告诉你「将分成 N 页」。

歌词框里按 Enter 是**换行**，不会上屏——放心按。

---

## ⚠️ Enter 键不送出

打中文时你会用 Enter 选词——**Enter 不会把内容送上屏**，放心按。
送出只有 **F9**。

## 屏幕上会看到什么

```
┌────────────────────────────────────────────┐
│                                            │
│              （PPT 正常放映）               │
│                                            │
├────────────────────────────────────────────┤
│  神爱世人，甚至将他的独生子赐给他们，        │  ← 半透明黑底
│  叫一切信他的，不至灭亡，反得永生。          │
│  2/3                       约翰福音 3:16   │  ← 页码（左）  出处（右）
└────────────────────────────────────────────┘
```

只占屏幕**下面三分之一**，PPT 上半部分照常看得见。

## 出错了怎么办

**所有错误都只出现在控制窗口，副屏永远不会显示报错。**

| 控制窗口显示 | 什么意思 |
|---|---|
| `经文 → 约翰福音 3:16` | 认出来了，可以按 F9 |
| `自由文本 → 原样上屏` | 不是经文格式，会照原样投 |
| `✗ 约翰福音 3 章只有 36 节` | 节号打大了，改一下 |
| `✗ 未知书卷「xxx」` | 书卷名不认识，换个写法 |
| `输入法组合中…` | 候选词还没确认，先按空格或数字选词 |
| `✗ 「约3:99」：约翰福音 3 章只有 36 节` | 连续引用里**第二处**写错了，引号里就是出错那一段 |

**按 F9 没反应？** 看控制窗口底部状态栏的「热键」那一格：
如果写着 `⚠ 热键 F9 注册失败`，说明有别的软件抢了这个键——用鼠标点「投放」按钮先顶上，散会后再排查。

## 三条纪律

1. **不要开第二个 Pulpit。** 两份会争抢热键，第二份按键没反应。
   *（「显示原文」勾选框和「⑥ 外观」折叠区平时都不要动——那些是彩排时调的。）*
2. **投放前看一眼预览区。** 预览区显示的就是副屏上的内容，一模一样。
3. **散会前按 F12 清屏。** 别让上一句经文留在屏幕上。
   *（副屏右上角那个常驻角标不受 F12 影响——它要在「⑦ 外观」里取消勾选才会消失。）*

## 出了状况找谁

日志在这里，报问题时一并带上：

```
%LOCALAPPDATA%\Pulpit\logs\pulpit-<日期>.log
```

程序**不会**因为出错而弹窗打断直播——真出了问题它会默默记进日志继续跑。
所以如果感觉哪里不对，去看日志。
